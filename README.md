# RappterBox Experiments

Public RAPP Vision channel for evidence-backed RappterBox experiments.

Every episode begins with a bounded prompt, shows the visible result, and ends
with source-linked evidence. Synthetic worlds and inhabitants are labeled as
such; hardware, executions, captures, and evidence records are not presented
as customer outcomes.

Watch through the canonical player:

https://kody-w.github.io/rapp-vision/#/channel/rappterbox
